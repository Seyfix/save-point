# SAVE POINT — игровая библиотека

## Тема

Игровая библиотека: подборка видеоигр разных жанров с описаниями,
фильтром, поиском и сортировкой. Зарегистрированный пользователь собирает
свою коллекцию «Мои игры» и отмечает прогресс: «Хочу пройти», «Играю», «Пройдено».

## Реализовано

- семантическая вёрстка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`);
- CSS-переменные в `:root`, Flexbox и Grid, шрифты Google Fonts (Russo One + Nunito);
- «липкая» шапка (`position: sticky`), бургер-меню на мобильных;
- адаптив: 4 → 2 → 1 колонка карточек (десктоп / планшет / телефон);
- слайдер на JavaScript: 4 слайда, стрелки, точки, автопрокрутка, пауза при наведении, свайп на телефоне;
- 12 карточек игр строятся из массива через `map()` и `join()`, есть hover-эффект;
- фильтр по жанрам, поиск по названию и студии, сортировка по названию и году;
- модальное окно «Подробнее» (закрывается крестиком, кликом по фону и клавишей Esc);
- коллекция «Мои игры» со статусами — хранится в localStorage отдельно для каждого пользователя;
- регистрация с проверками: пустые поля, формат email, пароль от 6 символов,
  совпадение паролей, повторный email, согласие с правилами;
- ошибки выводятся под полями, без `alert()`; индикатор надёжности пароля, кнопка «показать пароль»;
- вход, выход, имя пользователя в шапке после входа;
- личный кабинет: имя, email, дата регистрации, смена имени, статистика и список игр, кнопка «Выйти»;
- защита кабинета: без входа показывается «Доступ закрыт»;
- бонусы: Canvas-анимация «пиксельных звёзд», плавное появление блоков (IntersectionObserver),
  FAQ-аккордеон, форма подписки в подвале.
